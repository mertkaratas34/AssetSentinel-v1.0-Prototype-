# 📊 ARDA KOMUT ALLAHININ AMK (Prototype v1.0)
Kırklareli Üniversitesi Yazılım Mühendisliği öğrencisi olarak geliştirdiğim, gerçek zamanlı kripto ve emtia takip dashboard'u.

## 🚀 Özellikler
- **Gerçek Zamanlı Veri:** Binance ve Yahoo Finance üzerinden canlı fiyat takibi.
- **Cüzdan Entegrasyonu:** BtcTurk API ile güvenli bakiye sorgulama.
- **Şık Terminal UI:** `Rich` kütüphanesi ile zenginleştirilmiş kullanıcı arayüzü.
- **Güvenlik:** `.env` yönetimi ile API anahtarlarının korunması.

## 🛠 Kurulum
1. Repoyu klonlayın: `git clone https://github.com/mertkaratas34/AssetSentinel-v1.0-Prototype-.git`
2. Kütüphaneleri kurun: `pip install -r requirements.txt`
3. `.env` dosyasını oluşturun ve API anahtarlarınızı ekleyin.
4. Çalıştırın: `python3 main.py`
